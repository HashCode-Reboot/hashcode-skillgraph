# Contribuer à SkillGraph

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Les preuves de compétences doivent être traitées avec contexte, provenance, date et méthode de validation. Éviter les scores qui prétendent résumer une personne sans preuves.

Une PR doit documenter les données utilisées, la logique, les tests, les limites et les risques de biais.
